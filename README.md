# Human Intuition CAPTCHA

CAPTCHA based on human intuition and emotional understanding.

## Features

- Image grid challenge
- Interactive demo

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/human-sense-captcha-grid.git
cd human-sense-captcha-grid
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
